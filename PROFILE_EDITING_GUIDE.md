# Portfolio editing guide

This website follows a reference-inspired **profile sidebar + structured content** layout. Its written content is the portfolio owner's own.

## Section order

1. Digital Identity — personal introduction and background
2. Highlights & Successes — 2 projects, 7 certifications, research involvement
3. Featured Portfolios — two completed projects
4. Career Snapshot — education and student research involvement
5. Research Focus — detailed NLP and ABSA project
6. My Skills — professional and technical skills
7. Licenses & Certifications — seven verified-by-owner entries (credential URLs not yet supplied)
8. Let's Connect — current LinkedIn URL

## Edit the portfolio

Personal information, contact links, projects, skills, education and certifications are in `src/config/site.ts`. Empty external URLs are intentionally hidden. Replace them with public links before launch. There is no fake contact form and no stock portrait.

## Local development

```bash
npm install
npm run dev
npm run build
```
